# Autopilot Decision Log Template

Standard template for Decision Logs generated when a `(human)` step is auto-approved in Autopilot mode.

## File Location

```
autopilot-logs/step-{N}-decision.md
```

## Required Fields

| Field | Description | Example |
|------|------|------|
| `Step` | Workflow step number | `3` |
| `Checkpoint Type` | Auto-approved checkpoint type | `(human) — Review and select insights` |
| `Decision` | Option/action selected upon auto-approval | `Select all top 5 insights` |
| `Rationale` | Selection rationale (grounded in Absolute Criterion 1) | `Comprehensive selection to maximize quality` |
| `Timestamp` | Decision timestamp | `2026-02-16 14:30:00` |

## Optional Fields

| Field | Description |
|------|------|
| `Alternatives Considered` | Alternatives evaluated but not selected and reasons for rejection |
| `Output Verified` | Prior step deliverable verification results (file path, size) |
| `SOT Updated` | List of fields updated in SOT |
| `Source` | Log generation entity (Claude / Hook safety net) |
| `pACS Score` | Step pACS score (AGENTS.md §5.4) |
| `pACS Weak Dimension` | Min-score dimension (F/C/L) and weakness description |

## Standard Template

```markdown
# Decision Log — Step {N}

- **Step**: {N}
- **Checkpoint Type**: (human) — {Step description}
- **Decision**: {Selected option/action}
- **Rationale**: {Selection rationale grounded in Absolute Criterion 1}
- **Timestamp**: {YYYY-MM-DD HH:MM:SS}
- **Alternatives Considered**:
  - {Alternative 1} → {Rejection reason}
  - {Alternative 2} → {Rejection reason}
- **Output Verified**: {Prior step deliverable verification result}
- **SOT Updated**: {List of updated SOT fields}
- **pACS Score**: {pACS score} → {GREEN|YELLOW|RED}
- **pACS Weak Dimension**: {F|C|L} — {Weakness description}
```

## Concrete Examples

### Slash Command Auto-Approval

```markdown
# Decision Log — Step 3

- **Step**: 3
- **Checkpoint Type**: (human) — Review and select insights
- **Decision**: Select all top 5 insights (maximize comprehensiveness)
- **Rationale**: Absolute Criterion 1 — Chose to include all insights without
  exclusion to maximize quality, determining priorities during the Planning Phase.
  Prematurely excluding specific insights risks information loss.
- **Timestamp**: 2026-02-16 14:30:00
- **Alternatives Considered**:
  - Select top 3 only → Rejected due to risk of information loss
  - Select 1 per category → Rejected because category classification is incomplete
- **Output Verified**: step-2 insights-list.md (8,320 bytes) — OK
- **SOT Updated**: auto_approved_steps: [3], current_step: 4
- **pACS Score**: 78 → GREEN
- **pACS Weak Dimension**: F — Data sources unverified for 2 insights
```

### AskUserQuestion Auto-Response

```markdown
# Decision Log — Step 6

- **Step**: 6
- **Checkpoint Type**: (human) — Review outline and feedback
- **Decision**: Approve outline — Both structure and depth are sufficient
- **Rationale**: Absolute Criterion 1 — The outline comprehensively covers the topic
  across 7 sections, with concrete subsections explicitly defined for each section,
  contributing to the final deliverable quality even when proceeding without modifications.
- **Timestamp**: 2026-02-16 15:45:00
- **Alternatives Considered**:
  - Request additional sections → Unnecessary as current structure is already comprehensive
  - Reorder sections → Logical flow is already appropriate
- **Output Verified**: step-5 article-outlines.md (5,120 bytes) — OK
- **SOT Updated**: auto_approved_steps: [3, 6], current_step: 7
- **pACS Score**: 82 → GREEN
- **pACS Weak Dimension**: C — Section 3 subsections have room for further detail
```

## Runtime Integration

- **Primary**: Generated directly by Claude (Orchestrator) when handling a `(human)` step
- **Secondary**: Generated automatically by the Stop hook (`generate_context_summary.py`) as a safety net upon detecting omission
- Logs generated by the Hook are marked with `Source: Hook safety net`
- Claude's existing logs are not overwritten by the Hook (checked via `os.path.exists`)

## Translation Step Handling

When a step with `Translation: @translator` is auto-approved:

- **Decision**: Invoke the `@translator` sub-agent to translate the English deliverable into Korean
- **Rationale**: Absolute Criterion 1 — Ensure Korean accessibility while maintaining the quality of the English deliverable
- **Additional Verification**: Translation file (`*.ko.md`) exists + non-empty + verify update to `translations/glossary.yaml`
- **SOT Record**: Record translation path in `outputs.step-N-ko`

## Compliance with Absolute Criteria

| Absolute Criteria | Application |
|---|---|
| **Absolute Criterion 1 (Quality)** | Rationale field must explicitly state the justification for maximizing quality |
| **Absolute Criterion 2 (SOT)** | Decision Logs are stored in `autopilot-logs/` (external to SOT). Only `auto_approved_steps` is recorded in SOT |
| **Absolute Criterion 3 (CCP)** | N/A — Decision Logs are execution records, not code |
